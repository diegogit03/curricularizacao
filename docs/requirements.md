# Requisitos Levantados para um Sistema de Gestão Financeira

---

## 1. Declaração de Objetivos

O objetivo deste sistema é organizar os dados financeiros do autônomo, visando melhor gestão e decisões.

---

## 2. Requisitos Principais do Sistema

- Login para controle de acesso
- Cadastrar Transações
- Manter contas a pagar
- Manter contas a receber
- Manter usuários
- Manter categorias
- Emitir relatórios

---

## 3. Atores

- **Autônomo**

---

## 4. Lista de Eventos (Requisitos)

1. **Login**
2. **Cadastro de transações**
3. **Manter contas a pagar**
4. **Manter contas a receber**
5. **Marcar como paga contas a pagar**
6. **Marcar como recebida contas a receber**
7. **Manter usuários**
8. **Manter Categorias**
9. **Emitir relatório de Fluxo de caixa**
10. **Emitir relatório de Gastos por Categorias**
